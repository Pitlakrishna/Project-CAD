b# Security Policy

## Reporting a Vulnerability

The AI CAD Platform team takes security seriously. If you discover a vulnerability or security bug, please do NOT create a public issue.

Instead, report it responsibly:
- **Email**: security@aicadplatform.com
- **Response Time**: We acknowledge reports within 24 hours and aim to provide a remediation plan within 5 business days.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |
