# aicad-common (Python)

Shared library for Python microservices (`llm-service`, `analytics-service` analysis).

## Features
- **auth**: JWT token verification and tenant context propagation
- **logging**: Structured JSON logging and request tracing
- **events**: Pydantic event schemas, RabbitMQ AMQP publisher/consumer wrappers
- **observability**: OpenTelemetry tracing & Prometheus metrics exporters
- **errors**: Standard API error response models
